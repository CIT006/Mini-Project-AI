# Thai Smart Document & Receipt Inspector
Mini Project สำหรับวิชา Machine Learning (CIT0013)

ระบบผู้ช่วยตรวจสอบและวิเคราะห์เอกสาร/ใบเสร็จภาษาไทยอัจฉริยะ ด้วยการผสานพลังของ **Thai LLM** และ **AI For Thai**

---

## 🎯 ฟีเจอร์เด่นของระบบ
1. **Multimodal OCR & Document Analysis:** สแกนภาพใบเสร็จ/เอกสาร ดึงข้อความ และจำแนกรายการสินค้า ราคา วันที่ ยอดรวมสุทธิ
2. **Interactive Document Q&A:** แชตถาม-ตอบข้อสงสัยเกี่ยวกับเอกสารที่สแกนเข้ามาแบบสดๆ ผ่านโมเดลภาษาไทยชั้นนำ (**OpenThaiGPT**, **Typhoon**, **Pathumma**)
3. **Thai Text-to-Speech (TTS):** สังเคราะห์เสียงพูดภาษาไทยแจ้งสถานะการประมวลผลผ่านบริการ **AI For Thai (VAJA)**
4. **Sentiment Analysis:** วิเคราะห์ความรู้สึกและโทนของข้อความในเอกสารผ่าน **AI For Thai (SSense)**

---

## 🛠️ โครงสร้างโปรเจกต์
- [app.py](app.py): หน้าเว็บ UI พัฒนาด้วย Streamlit แบ่งหน้าจออัปโหลดรูปภาพและกล่องแชต
- [api_service.py](api_service.py): โมดูลเชื่อมต่อ API (ThaiLLM และ AI For Thai)
- [requirements.txt](requirements.txt): รายการไลบรารีที่จำเป็น

## 🚀 วิธีติดตั้งและรันโปรเจกต์
### เปิดแอปบน Windows
ใส่ API key ที่ใช้งานได้ในไฟล์ local [.streamlit/secrets.toml](.streamlit/secrets.toml) ก่อน จากนั้นดับเบิลคลิก [run_app.bat](run_app.bat) สคริปต์จะสร้าง virtual environment, ติดตั้ง dependencies และเปิด Streamlit ให้อัตโนมัติ ครั้งแรกต้องมีอินเทอร์เน็ตเพื่อติดตั้งไลบรารี

```toml
THAILLM_APIKEY = "ใส่คีย์ ThaiLLM"
AIFORTHAI_APIKEY = "ใส่คีย์ AI For Thai"
```

`THAILLM_APIKEY` จำเป็นสำหรับ OCR/ถาม-ตอบ/benchmark ส่วน `AIFORTHAI_APIKEY` ใช้สำหรับ VAJA TTS และ SSense หลังแก้ไขไฟล์ให้ปิดและเปิดแอปใหม่ ไฟล์ secrets จริงถูก ignore โดย Git อย่าส่งไฟล์นี้ลง repository

### รันด้วยตนเอง
```powershell
pip install -r requirements.txt
python -m streamlit run app.py
```

เปิด `http://localhost:8501` ในเบราว์เซอร์

## วิธีใช้งานเอกสาร
1. อัปโหลดรูปใบเสร็จหรือสลิป แล้วกดเริ่มประมวลผล
2. เทียบข้อความ OCR กับภาพ แก้ชื่อ วันที่ ยอด และรายการในฟอร์มตรวจทาน
3. กดบันทึกการตรวจทานและยืนยัน ระบบจึงเปิดให้ดาวน์โหลด JSON และ CSV (เมื่อมีรายการสินค้า)

ระบบถาม-ตอบเลือกใช้ Typhoon-S โดยอัตโนมัติ เพื่อลดขั้นตอนเลือกโมเดล จากการทดสอบคำถามสรุปกับข้อมูลตัวอย่างภายในหนึ่งรอบ รุ่นนี้ตอบครบและเร็วที่สุดในการทดสอบนั้น ความเร็วจริงขึ้นกับบริการและเครือข่าย ผู้ใช้สลับโหมดสีสว่าง/กลางคืนได้จาก sidebar (ค่าเริ่มต้นเป็นกลางคืน)

ภาพที่อัปโหลดจะถูกส่งไปประมวลผลผ่าน ThaiLLM API ส่วนผลลัพธ์อยู่ใน session ของแอป ไม่ใช่คลังเอกสารถาวร ควรดาวน์โหลดไฟล์ที่ยืนยันแล้วไปเก็บในระบบจัดเก็บที่ได้รับอนุญาต หลีกเลี่ยงการอัปโหลดเอกสารลับหรือข้อมูลส่วนบุคคลโดยไม่มีสิทธิ์
